# 速查清单

触发说法、错误用法与高频问题的快速对照表；详细规则以 SKILL.md 正文为准，本文件只做速查，不引入新规则。按需读取，不随主流程常驻上下文。

## 1. 触发说法对照

| 用户说法示例 | 是否命中 | 进入模式 |
|---|---|---|
| "初始化项目文档" / "建一套开发文档" / "给仓库加上 AI 文档"（尚无 AGENTS.md 时） | 命中 | 初始化 |
| "初始化项目文档" / "建一套开发文档" / "给仓库加上 AI 文档"（已有 AGENTS.md、未要求重建时） | 命中 | 更新（默认降级） |
| "从零重建文档" / "覆盖重新生成文档" / "文档推倒重来" | 命中 | 初始化（重写） |
| "创建 AGENTS.md" / "帮我写 AGENTS.md"（尚无 AGENTS.md 时） | 命中 | 初始化 |
| "项目结构变了，同步一下文档" / "文档过期了，刷新一下"（已有 AGENTS.md 时） | 命中 | 更新 |
| "补全/整理一下项目文档"（已有 AGENTS.md 时） | 命中 | 更新 |
| "补全/整理一下项目文档"（尚无 AGENTS.md 时） | 命中 | 初始化 |
| "写一份 README" / "加个 CONTRIBUTING" / "补个 SECURITY.md" / "整理 CHANGELOG" / "写接口文档" | 命中 | 单产物 |
| "初始化文档，顺便补一份 README"（尚无 AGENTS.md 时） | 命中 | 初始化（含扩展产物） |
| "帮我润色这段产品文案" / "帮我写周报" | 不命中 | — |
| "重构一下这段代码" / "修个 bug" | 不命中 | — |

- 模式判定不明确时向用户提问，不自行假定；判定规则见 SKILL.md Step 0。
- 输出结构与产物粒度示例另见 `examples.md`。

## 2. 错误用法

| 类型 | 说明 |
|---|---|
| 不适用 | 与项目结构无关的纯文字润色、非文档类任务（重构、修 bug、写文案） |
| 不适用 | 命令行调用；本技能未配置命令入口，仅对话中直接激活 |
| 禁止 | 编造技术栈、命令、接口等未确认信息；缺失项列入问题清单 |
| 禁止 | 更新模式整体重写未变更章节；一旦误判，回退并改按差异清单增量修订 |
| 禁止 | 已有文档体系时静默整体重写（未显式要求重建）；不读取旧文档、丢弃仅存于文档的信息 |
| 禁止 | 改写行为准则（Step 4）原文；擅自升级档位；自造映射表外的文件名 |
| 禁止 | 修改源码、package.json 等配置文件、提交 Git 等超范围操作 |

## 3. 高频问题与处理

| 问题 | 处理 |
|---|---|
| 配置文件读取失败 | 自动重试 1 次 → 跳过并改用目录/源码特征判断 → 仍不足归入"无法识别技术栈" |
| 技术栈无法识别 | 只写可确认信息，技术栈与命令章节留空，缺失项列入问题清单附表 |
| 目录扫描过大/不完整 | 限定根目录与一级子目录，聚焦配置与入口文件，不递归依赖目录 |
| monorepo 包边界不明 | 向用户提问后再拆分，不猜测 |
| 用户说明与现有文档冲突 | 以用户明确说明为准，文档中标注该条来源为用户说明 |
| 用户要求初始化但已有 AGENTS.md | 默认按更新模式全量核对修订；含"从零重建/覆盖"等显式重写词才整体重写，标 [重写] |
| 现有文档与实际严重不符 | 直接按现状重写对应文档，交付摘要第 4 项说明原因 |
| 更新被误判为初始化 | 检查是否整体重写；回退到现有文档，改按差异清单增量修订 |

## 4. 反馈速记

- 交付摘要：初始化/更新模式 6 项齐全；单产物模式仅第 2、6 项。
- 状态前缀：`[未动]` `[修订]` `[新增]` `[已删除]`；`[降级]` 为注记，追加在前缀后。
- 问题清单只在交付说明中输出一次，文档正文不写"待确认"。
- 完整格式见 `feedback.md`，首次交付前读取。
